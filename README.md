# Mother AI OS — website

Docusaurus site for [Mother AI OS](https://github.com/Mother-AI-OS/mother).

Split out of the main `mother` repo on 2026-08-16 so the Python package repo
carries code and developer docs only. Full `website/` history was preserved
through the split (28 commits).

## Develop

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

Deployment is via GitHub Pages — see `.github/workflows/` in this repo once the
deploy workflow is migrated over from the package repo.
